## Replacing or adding photos

1. Put a high-resolution JPEG (≥ 1600 px wide) in `assets/photos/` with a descriptive file name.
2. Run `npm run assets` — this creates responsive WebP sizes in `public/images/` and updates
   `src/config/image-manifest.json`.
3. Reference the file name (without extension) in the relevant component or in `src/config/site.ts`,
   with accurate alt text.
